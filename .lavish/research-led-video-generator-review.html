Provider roles

No silent substitutions

Tavily → research, search, extraction
Returns public-source evidence. The app stores provenance and exposes source removal before planning.
GPT-5.6 Luna → structured creative planning
Produces a schema-validated brief and storyboard; it does not become a source of factual claims.
ElevenLabs Eleven v3 on fal → narration
Generates a creator-selected narrator from approved script text. The returned audio URL becomes the approved NarrationAsset for VEED; no voice cloning or identity imitation.
Seedance on fal → visual scenes
Receives approved prompts and generation settings. Its native audio option is separate from the controlled narration asset.
VEED on fal → talking-video path
Fabric is image + approved narration audio. Lipsync v2 is talking video + approved narration audio. The creator selects the route.

Narrator input

Creator selects the narrator

ElevenLabs Eleven v3 on fal turns approved narration text into the audio asset used by VEED. These are project inputs, persisted with the narration asset and job provenance.

Delivery proof

What automated verification must demonstrate

  • New user sees an honest empty creation hub
  • Public URL yields a sourced Research Pack
  • Creator approves a labeled Storyboard
  • Generation Job reports live status or real failure
  • Completed output is a real provider URL

Browser tests use mocked provider transport. A separate, explicitly opted-in live smoke test verifies billable fal.ai calls. The existing repository tests only cover missing Fal-key handling and JavaScript syntax.
