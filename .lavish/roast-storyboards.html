02

What we score as funny

FunnyBench (issue #4) refuses to trust one LLM prompt to be the last word on comedy. Instead: generate 10–20 candidates, gate them on facts first, then let the creator pick winners in blind pairwise comparisons. These are the axes each candidate is judged on — the same ones annotated on every storyboard below.

Specificity

The joke depends on a real, technical detail of this repo. Swap the subject and the line dies.

evidence linkage · technical recognisability

Surprise / reversal

Setup points one way; the reveal turns. No line the audience could finish for you.

distinctness across batch

Escalation

Each beat raises the stakes on the last instead of restating it louder.

pacing · beat length

Fairness

Aimed at public decisions and artefacts — never protected traits or private life. "Too mean" is a reject.

too-mean rate

Freshness

No stock roast clichés. Penalise the generic "it's just an API wrapper" unless the repo earns it.

repeat / cliché rate

Payoff

The punch lands and the tag pays it back — a callback, not a shrug.

creator keep rate

Comedy Reference Card — the shape, not the script

  • Setup → reveal → punch → tag — the four-beat unit each scene is built from.
  • Specificity mechanism — how a technical detail (a file name, an issue count) becomes the joke.
  • Escalation mechanism — what makes beat 3 bigger than beat 2.
  • Deliberately NOT used — no real person's name as a style, no exact phrase, no imitated persona.
  • Trait bundle — one original instruction, e.g. mock-serious awards host · sharp technical specificity · quick escalation · no imitation.

04

Before any camera rolls

The wired generation path is Chatterbox TTS → VEED Fabric: it turns an approved script into a 480p talking-head. That path needs two things from you it cannot invent — and both are billable, so this stays a separate, explicit step after you choose the boards.

What "turn it into a video" will actually call

For each selected storyboard, the app runs the approved narration through Chatterbox (~$0.025 / 1,000 chars), then drives VEED Fabric with your presenter image + that audio. Seedance b-roll and per-scene evidence visuals are not wired yet — v1 is a single presenter delivering the script.
